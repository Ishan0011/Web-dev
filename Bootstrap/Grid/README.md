# 📌 What is the Bootstrap Grid?

The Bootstrap Grid System is a layout system used to create responsive web pages using rows and columns.

It is based on a 12-column layout and adapts automatically to different screen sizes.

# 🎯 Purpose of Grid

- Create responsive layouts

- Align content in rows and columns

- Control layout across devices

# Grid options 
Bootstrap’s grid system can adapt across all six default breakpoints, and any breakpoints you customize. The six default grid tiers are as follows:

- Extra small (xs) `.col-`
- Small (sm) `.col-sm-`
- Medium (md) `.col-md-`
- Large (lg) `.col-lg-`
- Extra large (xl) `.col-xl-`
- Extra extra large (xxl) `.col-xxl-`

# ↕️ Grid Vertical Alignment

Vertical alignment in the Bootstrap Grid is used to control how columns are aligned vertically inside a row.

It is handled using Flexbox utility classes.

# 🎯 Alignment Options

Bootstrap provides the following vertical alignment classes for rows:

### 1️⃣ `align-items-start`

Aligns columns to the top of the row.

### 2️⃣ `align-items-center`

Aligns columns to the center vertically.

### 3️⃣ `align-items-end`

Aligns columns to the bottom of the row.

# Individual Column Alignment

Use align-self-* to align a single column differently.

- `align-self-start`

- `align-self-center`

- `align-self-end`
