# `form-control` (Bootstrap)

form-control is a Bootstrap class used to style form input elements such as text fields, email inputs, passwords, and textareas.

It ensures a consistent, responsive, and user-friendly appearance.

#  Elements that Use form-control

- `<input>`

- `<textarea>`

- `<select>` (Bootstrap 5 uses form-select)

# Features of form-control

- Full-width by default

- Proper padding and borders

- Responsive and mobile-friendly
 
- Works with validation styles
