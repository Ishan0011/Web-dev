# Bootstrap Forms

Bootstrap Forms are used to create styled, responsive, and user-friendly form layouts using predefined Bootstrap classes.

They help reduce custom CSS and ensure consistent form design across devices.

# 🎯 Common Uses

- Login forms

- Registration forms

- Contact forms

- Feedback and surveys

# 🔑 Important Form Classes

- `form-control` → input, textarea, select styling

- `form-label` → label styling

- `form-check` → checkbox & radio buttons

- `form-select` → dropdown/select menu

- `mb-*` → spacing between fields
