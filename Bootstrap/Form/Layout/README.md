# Bootstrap Form Layouts

A form layout in Bootstrap defines how form elements (labels, inputs, buttons) are arranged and aligned on a page.

Bootstrap provides flexible layouts using its grid system and utility classes.

---

## Types of Form Layouts  

### Default (Vertical) Form


- Labels appear above inputs

- Most commonly used layout

- `mb-3`

### Horizontal Form

- Labels and inputs appear side by side

- Uses Bootstrap grid (`row` and `col-*`)
