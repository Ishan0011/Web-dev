# Checks and Radios (Bootstrap)

Checks (Checkboxes) and Radios (Radio buttons) in Bootstrap are used to select one or multiple options in a form.

Bootstrap provides predefined classes to style them consistently and responsively.

### Checkbox (Check)

Checkboxes allow users to select multiple options.

### Radio Button

Radio buttons allow users to select only one option from a group.

## Important Classes

- `form-check` → wrapper container

- `form-check-input` → checkbox or radio input

- `form-check-label` → label text

---

## Switches (form-switch) in Bootstrap

form-switch is a Bootstrap class used to convert checkboxes into toggle switches.

Switches are commonly used for on/off or enable/disable options.

# Common Uses

- Dark mode toggle

- Notifications on/off

- Settings and preferences
