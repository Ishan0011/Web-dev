# Arrays in JavaScript

An array is a data structure used to store a collection of multiple items under a single variable name.

It allows you to organize, manage, and manipulate ordered lists of data efficiently.

---

## Key Array Operations

- **Creating an Array** `let arr = ["apple", "banana", "mango"];`  
  Initializes a new array with multiple elements.

- **Accessing Elements** `arr[0]`  
  Retrieves an element at a specific index (e.g., returns `"apple"`).

- **Modifying Elements** `arr[1] = "orange";`  
  Changes the value of an element at a given index.

- **Multi-Dimensional Array Access** `arr[2][3]`  
  Retrieves the 4th element of the 3rd array, where `2` is the outer array index and `3` is the inner array element index.

---

Arrays provide powerful built-in methods to handle and process collections of data dynamically.
