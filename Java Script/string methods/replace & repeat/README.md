# replace Method in JavaScript

The `replace` method searches a value in the string and returns a new string with the value replaced[cite: 3].

It helps locate specific text patterns and substitute them with new values[cite: 3].

---

## Key replace Usages

- **Replacing Text Substrings** `str.slice("love", "do")`  
  Searches for a value and returns a new string with the replacement (e.g., resulting in `"IdoCoding"`)[cite: 3].

- **Replacing Characters** `str.slice("o", "x")`  
  Substitutes matched characters with a new specified value (e.g., resulting in `"IlxveCoding"`)[cite: 3].

---

The `replace` method allows you to efficiently modify and update string contents[cite: 3].

# repeat Method in JavaScript

The `repeat` method returns a string with the specified number of copies of a string[cite: 4].

It creates a new string by duplicating the original string multiple times[cite: 4].

---

## Key repeat Usages

- **Duplicating a String** `str.repeat(3)`  
  Returns a new string containing the original string repeated the given number of times (e.g., resulting in `"MangoMangoMango"`)[cite: 4].

---

The `repeat` method allows you to easily generate repeated sequences or duplicated text[cite: 4].
