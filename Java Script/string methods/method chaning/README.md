# Method Chaining in JavaScript

Method chaining means using one method after another[cite: 2].

The order of execution for chained methods will be from left to right[cite: 2].

---

## Key Method Chaining Usage

- **Chained Methods Example** `str.toUpperCase().trim()`  
  Executes multiple string methods sequentially in a single line from left to right[cite: 2].

---

Method chaining helps you write cleaner, more concise, and readable code when performing multiple operations.
