GitHub automatically shows the PRO badge on a user's profile if they have an active GitHub Pro subscription.

How to get it
Sign in to your GitHub account.
Go to Settings.
Select Billing and plans.
Upgrade to GitHub Pro and complete the payment.

Once your subscription is active, the PRO badge will appear on your profile.

What GitHub Pro includes
⭐ PRO badge on your profile
More GitHub Actions minutes and storage
Advanced code search and developer features
More powerful GitHub Copilot usage options (Copilot itself is a separate subscription)
Additional repository and collaboration feature
